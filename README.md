## 🔧 Installation
1. **Clone the Repo**  
   ```bash
   git clone https://github.com/Nallanos/skynalytic.git
   ```
2. **Install Dependencies**  
   ```bash
   cd skynalytic
   npm install
   ```
3. **Setup Configuration**  
   Update `.env` with your Bluesky API keys and settings.

4. **Run the App**  
   ```bash
   npm run dev
   ```
