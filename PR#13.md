Problem
The migration to skylume.app had inconsistent domain references, with email addresses still using the old @blueskybot.com domain while meta tags and configurations were updated to skylume.app. Users needed both domains to be operational with proper redirects to maintain backward compatibility.

Solution
This PR fixes the domain migration issues by:

1. Email Domain Consistency
Updated all email addresses across the application to use the new skylume.app domain:

Contact page: support@skylume.app, sales@skylume.app
Terms of Service: support@skylume.app
Privacy Policy: privacy@skylume.app
2. Automatic Domain Redirects
Added DomainRedirectMiddleware that automatically redirects old domain requests to the new domain:

// Production behavior:
// bluesky-bot.com → 301 redirect to skylume.app
// www.bluesky-bot.com → 301 redirect to skylume.app
The middleware:

Only runs in production environment
Uses 301 permanent redirects for SEO benefits
Preserves full URLs including paths and query parameters
Runs early in the middleware stack for optimal performance
3. Updated Documentation
Enhanced DOMAIN_MIGRATION.md with comprehensive migration guide including:

DNS migration checklist
Email infrastructure changes
SEO considerations
Post-migration cleanup steps
Technical Details
Backend configurations were already correct - CORS and CSP properly supported both domains. The main issues were:

Inconsistent email domain branding
Missing server-side redirect logic for seamless user experience
Files changed:

app/middleware/domain_redirect_middleware.ts (new)
start/kernel.ts (middleware registration)
inertia/pages/contact-us.tsx (email updates)
inertia/pages/terms.tsx (email updates)
inertia/pages/privacy.tsx (email updates)
DOMAIN_MIGRATION.md (documentation)
Result
✅ Both domains are fully operational
✅ Old domain automatically redirects to new domain
✅ Email addresses consistent with new branding
✅ SEO rankings preserved through 301 redirects
✅ Zero breaking changes for existing users

Users can now seamlessly access the application from both domains while the transition to skylume.app as the primary domain is complete.
